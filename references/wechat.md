# 微信规格与验收

制作基线核对于 2026-11-06，投稿前重新查看[微信官方制作规范](https://sticker.weixin.qq.com/pages/guide#/#/makingSpecifications#specifications_stickers)。这份快照不是未来规则保证。

| 项目 | 本流程基线 |
|---|---|
| 专辑数量 | 8–24 张 |
| 动态表情 | GIF，240×240，每张 ≤500,000 字节 |
| 缩略图 | PNG，120×120，每张 ≤50,000 字节 |
| 封面 | PNG，240×240，≤500,000 字节 |
| 图标 | PNG，50×50，≤100,000 字节 |
| 横幅 | JPEG，750×400，≤500,000 字节 |
| 可选赞赏引导图 | JPEG，750×560，≤500,000 字节 |
| 可选赞赏致谢图 | JPEG，750×750，≤500,000 字节 |

技术校验包含：全部解码帧、透明像素、无限循环、真实动态变化、至少 2px 边距、文件大小、配套素材和最终 ZIP 内容。不能验证：宠物是否像、文字是否自然、视觉边缘质量、平台是否接受、真机聊天效果或审核结果。

高分辨率 GIF 供留存；实际投稿用 `wechat/`。ZIP 只包含成品、配套图、文案、预览及技术报告，不含原始照片、清单中的本地绝对路径或凭据。生成提示词与原始照片单独保存在用户自己的工作目录。
